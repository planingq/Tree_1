# جذور — شجرة العائلة التفاعلية

إصدار MVP عربي باتجاه RTL، يعمل محليًا داخل المتصفح. بُني على React وTypeScript وVite وTailwind CSS وReact Flow، مع Dagre لترتيب الفروع. جميع الأسماء التجريبية خيالية.

## التشغيل

المتطلبات: Node.js 22.12 أو أحدث (اختُبر على Node 24)، وnpm.

```bash
npm install
npm run dev
```

افتح عنوان خادم Vite الذي يظهر في الطرفية. لا توجد مفاتيح سرية أو خدمة خارجية مطلوبة. اختر «مدير» أو «مشاهد» في شاشة الدخول التجريبية. اختيار الدور يقيّد أدوات الواجهة لأغراض العرض فقط، وليس حماية أمنية.

```bash
npm ci             # تثبيت قابل للتكرار من package-lock.json
npm run build      # فحص TypeScript وبناء dist
npm run preview    # معاينة البناء محليًا
npm test           # اختبارات Vitest
```

لا توجد حاجة إلى الموقع الثابت القديم؛ أصبح index.html نقطة دخول Vite. حُذفت ملفات script.js وstyle.css القديمة بعد نقل التطبيق إلى src.

## المكتمل

- لوحة تحكم عربية متجاوبة، وتنقل إلى الشجرة والأفراد والاستيراد والإحصائيات والإعدادات.
- شجرة عمودية وأفقية من اليمين إلى اليسار، بتكبير وتحريك وخريطة مصغرة وإعادة ضبط.
- طي فرع كل شخص وفتحه، والبحث بالاسم أو المعرّف مع فتح سلسلة آبائه وتوسيط بطاقته. عند تشابه الأسماء، يُختار أول تطابق؛ استخدم ID لتحديد الفرد بدقة.
- بطاقات تعرض الحالة والأبناء المباشرين وإجمالي الذرية، مع نافذة تفاصيل وحقول مخصصة.
- جدول ببحث وتصفية وفرز وصفحات، وإضافة وتعديل وحذف مع تأكيد. المعرّف غير قابل للتعديل بعد الإنشاء لحماية المراجع. لا يُسمح بحذف أب لديه أبناء؛ انقل أبناءه إلى أب آخر أولًا. التعديلات التي تنشئ دورة أو مرجعًا مفقودًا مرفوضة.
- قراءة XLSX وXLS، ومطابقة أعمدة قابلة للتغيير، ومعاينة وأخطاء وتحذيرات برقم الصف، وتنزيل نموذج. الاستبدال يتطلب تأكيدًا صريحًا.
- إحصائيات الذرية والأحياء والمتوفين وعمق الأجيال وأعداد كل جيل وكل فرع رئيسي.
- حفظ محلي للتطوير، مع معالجة فساد التخزين أو امتلائه، واستعادة بيانات العرض بتأكيد المستخدم.
- خط Noto Sans Arabic محلي دون استدعاء Google Fonts، وحالات تحميل وفشل، وحوارات تدعم Escape وحصر التركيز.

## Excel ونموذج البيانات

العناوين الأساسية، وجميعها مطلوبة كأعمدة حتى عندما تكون قيمة الأب فارغة:

| العمود | المعنى |
| --- | --- |
| ID | معرّف نصي فريد |
| الحالة | 1 حي، 2 متوفى |
| ترتيب الشخص بين إخوته | يبدأ من 1 للأكبر، ثم 2 ثم 3… لترتيب الأبناء فقط، **وليس عمق الجيل** |
| الاسم | اسم الفرد |
| أسم الاب | اسم الأب للعرض والتحذير عند عدم مطابقته |
| يرأسه | ID الأب، فارغ للجذر |

تُقبل اختلافات الهمزات والمسافات مثل «اسم الأب». يُقبل أيضًا الاسم القديم «تسلسل الجيل» أو «ترتيب الإخوة» لعمود الترتيب. لا تظهر قيمة الترتيب في الشجرة أو التفاصيل أو جدول الأفراد؛ يمكن تعديلها في نموذج الفرد وتظهر في معاينة Excel للتحقق منها. احفظ ID و«يرأسه» بتنسيق **نص** في Excel قبل إدخالها؛ إذا حذف Excel الأصفار سابقًا فلا يمكن استعادتها تلقائيًا. نقرأ النص المعروض للحفاظ أيضًا على التنسيقات الرقمية ذات الأصفار.

تُقرأ أول ورقة عمل، بحد 10 ميجابايت و20 ألف فرد. الصف الأول للعناوين ولا تُقبل عناوين فارغة أو مكررة. الصفوف الخالية تُتجاهل مع الحفاظ على أرقام الصفوف الأصلية. الأعمدة الأخرى محفوظة كـ `customFields: Record<string,string>`، وتظهر في تفاصيل الفرد ويمكن تعديلها. القيم المخصصة نصية في هذه النسخة.

يمنع الاستيراد: المعرّفات الناقصة أو المكررة، الحالات غير الصحيحة، الأسماء الفارغة، ترتيب الإخوة غير الصحيح، مراجع الآباء المفقودة، الارتباط بالنفس، والدورات. الأسماء المكررة واختلاف اسم الأب وتعدد الجذور تحذيرات لا تمنع الاعتماد؛ المرجع دائمًا ID. يدعم التطبيق غابة من جذور مستقلة.

**مكتبة Excel:** يستخدم اسم الاستيراد `xlsx` alias إلى `@e965/xlsx@0.20.3`، وهي إعادة توزيع مجتمعية لـSheetJS CE عبر npm. اختيرت لأن خادم `cdn.sheetjs.com` محجوب في بيئة التنفيذ، وتجنبًا للإصدار القديم 0.18.5 على اسم npm الأصلي. الحزمة مثبتة بسلامة integrity في القفل. راجع مصدر التوزيعة والتراخيص ومتطلبات سلسلة التوريد قبل الإنتاج؛ يمكن استبدال alias بالتوزيع الرسمي للإصدار المدقق عند توفر الوصول. لا تُرفع الملفات إلى أي خدمة خارجية، ولا تُنفّذ وحدات ماكرو.

## منطق العلاقات والأداء

`analyzeFamily` يبني فهارس بالمعرّف وأبناء كل أب، ثم يحسب العمق بالاجتياز العرضي ومجاميع الذرية بتمرير عكسي دون recursion. الزمن O(n) للحساب الأساسي، إضافة إلى ترتيب الإخوة O(n log n) في أسوأ الحالات. `validatePeople` يكشف الدورات بمسارات تكرارية تُنجز كل معرّف مرة واحدة. إجمالي ذرية الشخص لا يشمله، بينما أحجام الفروع تشمل مؤسس الفرع. الفروع الرئيسية هي أبناء كل جذر مع ذريتهم؛ الجذر ذو الأبناء مستثنى من أعداد الفروع، والجذر المنفرد يُحسب فرعًا مستقلًا.

تُحفظ الحسابات في useMemo عند ثبات البيانات. العقد غير الظاهرة خارج مجال العرض لا تُرسم، والفروع المطوية لا تدخل في التخطيط. مكتبة التخطيط Dagre وواجهة الإحصائيات الكاملة قد تبطآن مع آلاف العقد المفتوحة؛ حد الاستيراد ليس ضمانًا لسرعة التخطيط بهذا الحجم. تحسين لاحق: Worker للتخطيط والتحليل، وعرض إحصائيات افتراضي وطي افتراضي حسب العمق.

## الخصوصية وحدود النسخة

**لا تستخدم هذه النسخة لحفظ بيانات عائلية حقيقية ولا تعتبر شاشة الدخول حماية.** التطبيق ثابت؛ لا يوجد خادم أو قاعدة بيانات أو كلمات مرور أو مصادقة إنتاجية. يستطيع مستخدم الجهاز تغيير الدور وقراءة localStorage. لا تكفي حماية المسارات أو إخفاء الأزرار في React.

لا يُرسل التطبيق البيانات للخارج ولا يحتوي تتبعًا أو رفعًا تلقائيًا. البيانات المستوردة والتعديلات تُحفظ في مفتاح `judhur-demo-family-v1` في متصفح الجهاز فقط؛ مسح بيانات المتصفح يفقدها. الجلسة التجريبية لا تُحفظ ويعاد اختيارها عند تحديث الصفحة.

قبل النشر الفعلي يلزم تنفيذ:

1. Backend وAPI وقاعدة بيانات بعلاقات أبوة سليمة ومعاملات ذرية وإعادة التحقق من الاستيراد على الخادم.
2. مصادقة آمنة عبر مزوّد موثوق أو جلسات HttpOnly/Secure/SameSite، وتفويض admin وviewer على **كل طلب** مع عزل العائلات.
3. TLS وحماية CSRF عند الحاجة وتحديد المعدل وسجل تدقيق وسياسات وصول واحتفاظ ونسخ احتياطية وحذف.
4. مراجعة سلسلة التوريد وحدود الملفات والمعالجة المعزولة وقياسات أداء واختبارات وصول وأمان.

واجهة `AuthService` جاهزة لاستبدال موائم العرض بموائم خادم. الواجهات لا تطلب كلمات مرور ولا تحتوي أسرارًا. لا يوجد رفع إلى GitHub أو نشر تلقائي ضمن هذا التنفيذ.

## التحقق المنفذ

نجح تثبيت الحزم والبناء وفحص TypeScript واختبارات Vitest، بما فيها شجرة متفرعة وأسماء مكررة وغابة جذور وسلسلة من 15 ألف جيل، وقراءة XLS/XLSX فعلية، وأرقام صفوف الأخطاء والتحقق من سلامة التخزين المحلي. كما أُجري اختبار Chromium على الحاسوب والجوال للإضافة والتعديل والحقول المخصصة والحذف، والحفظ بعد التحديث، وطي الفروع والبحث والاتجاه الأفقي، وتنزيل النموذج وإعادة استيراده بتأكيد، واستعادة العرض ودور المشاهد. تدقيق `npm audit` عند التنفيذ لم يرصد ثغرات معروفة؛ لا يمثل ذلك ضمانًا أمنيًا.

يمكن إعادة اختبار المتصفح اختياريًا عبر `scripts/browser-smoke.py` في بيئة تحتوي Python Playwright وChromium، مع خادم التطوير قيد التشغيل. يشغّل متصفحًا معزولًا ببيانات تجريبية؛ لا تستخدمه على نسخة بيانات حقيقية. يحتاج socket وتشغيل المتصفح إلى سماح بيئة التنفيذ.

```bash
# بعد تثبيت Python Playwright في بيئة اختبار منفصلة، إن لم يكن متاحًا:
APP_URL=http://127.0.0.1:5173/ CHROMIUM_PATH=/usr/bin/chromium python3 scripts/browser-smoke.py
```

لا يُثبّت سكربت المتصفح أي حزم تلقائيًا، ويحفظ لقطات مؤقتة وملف Excel في `/tmp`. اختبارات `npm test` لا تحتاج متصفحًا أو خادمًا.

## وضوح الشجرة ومسار الأسلاف والتصدير

- يبدأ العرض بحجم مقروء بدل تصغير جميع الأفراد تلقائيًا. اسحب الرسم لاستكشاف الفروع. «حجم مقروء 100٪» يركز على الشخص المحدد بالبحث أو الجذر؛ «عرض الكل» يصغّر الرسم ليعرض امتداده كاملًا. قد تصبح الأسماء صغيرة في هذا الوضع عند كثرة الأفراد.
- اضغط بطاقة أي شخص ثم «عرض المختار وأسلافه إلى الجيل 1». يظهر هذا الشخص وأبوه وجده حتى الجذر فقط، دون الإخوة أو الأبناء. مثال: اختيار شخص من الجيل التاسع يعرض تسعة أشخاص على سلسلة آبائه. يبقى الجذر أعلى الرسم أو يمينه. يمكن العودة للعائلة كاملة، ولا تُحذف أي بيانات. البحث الجديد يعود إلى عرض العائلة كاملة.
- «تصدير وطباعة» يدعم نطاق الأفراد الظاهرين (بما فيه مسار الأسلاف والفروع المفتوحة)، أو جميع أفراد العائلة. أعداد الذرية في البطاقات تظل محسوبة من كامل العائلة.
- «تنزيل Excel» يصدر بيانات النطاق المختار مع ID نصي وترتيب الإخوة والحقول المخصصة، ويمكن إعادة استيراده. هذا تصدير للبيانات، وليس لصورة الرسم.
- للطباعة/PDF اختر A4 أو A3 أو A2 أو A1 أو A0، واتجاهًا أفقيًا أو عموديًا. «حجم مقروء على صفحات متتابعة» يحافظ على عرض بطاقة 50 أو 65 أو 80 مم ويقسم الرسم إلى شبكة صفحات مرقمة لتجميعها. قد يعبر الخط أو البطاقة حدود صفحتين عند التجميع؛ الصفحات أجزاء متجاورة من نفس الرسم، وليست أشجارًا مستقلة. الحد 200 صفحة في العملية الواحدة.
- «الشجرة كاملة في صفحة واحدة» مناسب للورق الكبير؛ قد يصغر النص إن كانت الشجرة واسعة جدًا. لا يمكن ضمان وضوح آلاف الأسماء على ورقة واحدة صغيرة.
- اضغط «فتح معاينة الطباعة / PDF»، ثم في النافذة الجديدة «طباعة / حفظ PDF». اختر «حفظ بتنسيق PDF» أو الطابعة. استخدم مقياس 100٪ وهوامش 10 مم وأوقف رؤوس وتذييلات المتصفح. اختيار حجم ورق غير مدعوم في الطابعة يتطلب حفظ PDF وإرساله إلى مطبعة تدعم المقاس. إذا منع المتصفح النافذة الجديدة، اسمح بالنوافذ المنبثقة للموقع.
- الرسم المطبوع SVG متجهي يحافظ على قابلية تكبير الخطوط والنصوص العربية، دون التقاط صورة منخفضة الدقة أو رفع بيانات لخدمة خارجية. يستخدم خطوط Tahoma/Arial المتوفرة في نظام الطباعة.

اختبارات إضافية: `src/tests/export.test.ts` يغطي تسعة أجيال، حساب توزيع الصفحات وأحجام الورق، تأمين النصوص المصدرة وإعادة استيراد Excel. `scripts/browser-export-smoke.py` اختبار Chromium اختياري لشجرة خيالية من 159 شخصًا ومسار تسعة أجيال؛ يكتب PDFs وXLSX ولقطات في `/tmp` فقط ولا يستخدم بيانات عائلية حقيقية. نجح إنتاج PDF A0 من صفحة واحدة وPDF A4 متعدد الصفحات مع نص عربي قابل للاستخراج.
