# مساحتي — مشروع ويب عربي بسيط

صفحة رئيسية عربية بتصميم حديث وألوان هادئة، تدعم اتجاه الكتابة من اليمين إلى اليسار (RTL) وتتكيف مع الجوال والكمبيوتر.

## التشغيل
1. نزّل ملفات المستودع إلى جهازك.
2. افتح ملف `index.html` بالنقر المزدوج.
3. ستظهر الصفحة في متصفح Chrome أو Edge أو Firefox.

لا تحتاج إلى تثبيت Node.js أو مكتبات أو برامج إضافية. يعمل المشروع دون إنترنت بعد تنزيله.

## الملفات
- `index.html`: هيكل الصفحة والمحتوى العربي.
- `style.css`: الألوان والخطوط والتصميم المتجاوب والوضع الداكن.
- `script.js`: تفاعل الأزرار وتحديث السنة تلقائيًا.
- `README.md`: دليل المشروع وطريقة تشغيله.

## التجربة
- اضغط «استكشف المميزات» للانتقال إلى المميزات.
- اضغط «رسالة ترحيب» لإظهار رسالة.
- اضغط زر القمر للتبديل إلى الوضع الداكن، ثم الشمس للعودة.

## التعديل
عدّل النصوص في `index.html`، والألوان في `style.css`، والتفاعلات في `script.js`. احفظ الملفات وحدّث الصفحة في المتصفح.
